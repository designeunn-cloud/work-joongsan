# 업무 관리 프로그램

엑셀 업무요청서를 자동으로 읽어 폴더를 정리하고, 진행상황을 대시보드에서 관리하는 사내 도구입니다.

## ⚠️ 감시 폴더 설정 (가장 먼저 확인하세요)

프로그램은 지정된 **"작업" 폴더**를 감시합니다. 이 폴더에 엑셀 요청서를 넣으면 자동으로 읽고, 결과 폴더(`날짜_업무요청내용_제품명`)를 만들어 원본 파일을 그 안으로 옮깁니다.

- 감시 폴더 경로는 `.env` 파일의 `WATCH_FOLDER_PATH` 값으로 정해집니다.
- **기본값**: `/Users/eun/Data/클로드/업무 프로그램/작업`
- 감시 폴더를 옮기거나 이름을 바꾸고 싶다면 **코드를 수정할 필요 없이** `.env`의 이 값만 바꾸면 됩니다.
- 감시는 "작업" 폴더 **바로 아래(최상위)**의 `.xlsx`/`.xls` 파일만 대상입니다. 프로그램이 만든 결과 폴더 안은 다시 감시하지 않습니다.

```
업무 프로그램/
├── 작업/     ← 여기에 엑셀을 넣으면 됨 (WATCH_FOLDER_PATH)
└── app/      ← 이 프로그램 소스코드
```

## 처음 설정하기

### 1. 환경변수 채우기

`.env.example`을 참고해 `.env`에 값을 채웁니다.

| 변수 | 설명 |
|---|---|
| `WATCH_FOLDER_PATH` | 위에서 설명한 감시 폴더 절대경로 |
| `INTERPRET_MODE` | `rules`(기본값, 무료) 또는 `ai`(유료, Claude API) — 아래 "해석 방식" 참고 |
| `ANTHROPIC_API_KEY` | `INTERPRET_MODE="ai"`일 때만 필요 (유료) |
| `NOTION_TOKEN` | 담당자/제품명 DB 동기화에 사용 (아래 발급 방법 참고) |
| `NOTION_ASSIGNEE_DB_ID` | 담당자 DB data source ID (기본값 이미 입력됨) |
| `NOTION_PRODUCT_DB_ID` | 품명 DB data source ID (기본값 이미 입력됨) |

### 2. Notion Integration 토큰 발급

1. https://www.notion.so/my-integrations 접속 → **New integration** 생성 (이름 예: "업무프로그램")
2. 생성된 **Internal Integration Token**(`ntn_...`로 시작) 복사 → `.env`의 `NOTION_TOKEN`에 입력
3. 담당자 DB, 품명 DB 페이지에서 각각 우측 상단 `...` → **연결 추가(Add connections)** → 방금 만든 통합 선택
   - 이 연결을 안 해주면 API가 데이터를 못 읽습니다.

### 3. 패키지 설치 및 DB 준비 (최초 1회)

```bash
npm install
npx prisma migrate deploy
```

### 4. 노션 마스터데이터 동기화 (최초 1회, 이후엔 대시보드에서 버튼으로도 가능)

```bash
npm run sync:notion
```

## 실행하기

```bash
npm run dev:all
```

- 웹 대시보드: http://localhost:3000
- 동시에 "작업" 폴더 감시 프로세스도 함께 실행됩니다.

웹서버와 감시 프로세스를 따로 실행하고 싶다면:

```bash
npm run dev       # 웹 대시보드만
npm run watcher   # 폴더 감시만
```

## 동작 방식

1. "작업" 폴더에 엑셀이 들어오면 셀 텍스트를 모두 추출합니다 (이미지는 읽지 않습니다).
2. 노션에서 동기화한 담당자/제품명 목록을 참고해 담당자·부서·브랜드·제품명·업무요청내용·요청일을 해석합니다.
3. 필수 항목(담당자/업무요청내용/요청일)을 확신 있게 해석하지 못하면 폴더를 만들지 않고 대시보드 "확인 필요" 섹션에 사유와 함께 남깁니다.
4. 해석에 성공하면 `날짜_업무요청내용_제품명` 폴더를 만들고 원본 엑셀을 그 안으로 옮긴 뒤, 대시보드에 "진행중" 상태로 등록합니다.
5. 대시보드에서 "완료" 버튼을 눌러야 완료 상태로 바뀝니다.

## 해석 방식: rules(무료, 기본값) vs ai(유료)

`INTERPRET_MODE` 값으로 전환합니다 (`.env`).

- **`rules` (기본값, 비용 없음)**: 엑셀 셀에서 "요청자"/"담당자"/"요청일자"/"요청내용" 같은 라벨을 찾아 바로 옆 셀 값을 읽고, 노션에서 동기화한 담당자 20명·제품명 152개 목록과 전체 텍스트를 매칭합니다. 라벨 표현이 완전히 다르거나 값이 이미지로만 있는 경우는 놓칠 수 있고, 그런 경우는 "확인 필요"로 남습니다. API 키가 전혀 필요 없습니다.
- **`ai` (유료)**: Claude API(`ANTHROPIC_API_KEY` 필요, [console.anthropic.com](https://console.anthropic.com)에서 별도 결제)로 내용을 이해해서 해석합니다. 부서마다 완전히 다른 양식에도 더 잘 대응하지만, 엑셀 1건당 소액의 API 비용이 발생합니다. Claude.ai Pro 구독과는 별개의 결제입니다.

두 모드 모두 동일한 방식(폴더 생성, DB 등록, 대시보드)으로 동작하므로 나중에 언제든 `.env`의 `INTERPRET_MODE`만 바꿔서 전환할 수 있습니다.

## 문제 해결

- **"확인 필요"에 계속 쌓인다**: `rules` 모드에서는 엑셀 라벨 표현이 다르거나 값이 이미지로만 있으면 자주 발생할 수 있습니다. 노션 동기화가 안 되어 담당자/제품명 매칭이 안 되는 경우도 있으니 대시보드 우측 상단 "노션 동기화" 버튼을 눌러보세요. 정확도를 더 높이고 싶다면 `ai` 모드로 전환을 고려해보세요.
- **감시가 안 된다**: `npm run watcher`를 별도 터미널에서 실행해 에러 로그를 확인하세요. `WATCH_FOLDER_PATH` 경로가 실제로 존재하는지 확인하세요.
