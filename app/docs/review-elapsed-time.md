# 진행 → 검토 시간 입력

소요시간 입력창의 **진행→검토 시간** 버튼은 가장 최근에 완료된 `in_progress → submitted` 상태 구간을 사용한다.

- 시작은 해당 검토 직전의 실제 진행중 진입, 진행중 등록 또는 작업 날짜 갱신 기록이다.
- 진행중 상태에서 코멘트만 기록한 시각은 시작 시각을 바꾸지 않는다.
- 보류 후 재개했다면 마지막 재개부터 계산한다. `review`는 보류이며 검토(`submitted`)와 구분한다.
- 타이머 측정값 대신 상태 시각 사이의 전체 경과시간을 계산한다. 휴식·야간·주말을 빼지 않는다.
- 구간이 날짜를 넘기면 한국 시간 기준으로 선택한 날짜와 겹치는 부분만 입력한다. 최근 구간 전체 시간과 날짜별 시간은 구분해 안내한다.
- 기존 소요시간 규칙대로 0.1시간 단위로 올림한다.

계산 조회는 읽기 전용이다. 구간 또는 시작 기록이 없거나 해당 날짜에 겹치는 시간이 없으면 값을 저장하지 않고 사유를 표시한다. 간편 입력에서는 기존 프리셋처럼 선택한 값을 저장하고, 완료 확인창에서는 입력값만 준비한 뒤 ‘저장하고 완료’를 눌러 함께 저장한다.

일반 저장 기능을 재사용하므로 직접 입력으로 전환할 때의 자동 시간 해제, 측정 중 수정 방지, 일지·시트 동기화 규칙을 유지한다.
