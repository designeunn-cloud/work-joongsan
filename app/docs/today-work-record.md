# 오늘 작업 기록

진행중 업무의 카드, 테이블 상태 칸, 상세창에서 `오늘 작업 기록`을 연다. 한국 날짜 기준 오늘의 기존 일지 내용과 소요시간을 불러와 편집하고 함께 저장한다. 세부할일이 남아 있어도 사용할 수 있다.

- 직접 입력은 오늘 총 소요시간을 교체한다. 같은 값을 다시 저장해도 합산되지 않는다. 기존 시간 규칙에 따라 0.1시간 단위로 올림한다.
- 창 상단의 `시간 측정 시작`으로 타이머를 켠다. 오늘 합계를 초 단위로 확인하고 `일시정지`·`측정 재개`를 사용할 수 있다. 이 동작으로 작성 중인 작업 내용은 지워지지 않는다.
- 창을 닫아도 타이머는 유지되며 화면 하단 측정 바에서 조작할 수 있다. 작성 중인 내용은 `측정 종료하고 기록`을 눌러야 저장된다.
- 직접 입력한 시간이 아직 저장되지 않았다면 먼저 저장한다. 자동 시간은 창에서 해제한 뒤 측정하며, 다른 업무의 타이머가 있으면 하단에서 먼저 종료한다.
- 해당 업무를 측정 중이거나 일시정지한 경우에는 `측정 종료하고 기록`으로 정산한다. 자정을 걸친 측정은 기존 날짜별 정산 규칙을 따른다.
- 저장하면 오늘 일지에 업무를 포함하고 기존 시트 자동 동기화 흐름을 사용한다. 오늘 내용과 시간 이외의 일지 필드는 유지한다.
- 전체 업무의 상태, 검토일, 종료일, 세부할일 완료 여부는 바꾸지 않는다. 완료·검토 상태 변경 시 이미 기록한 시간을 다시 더하지 않는다.
- 다른 창에서 기록·타이머·업무 상태가 바뀌거나 한국 날짜가 넘어가면 저장을 거절하고 최신 기록을 다시 불러오도록 안내한다.
- 내용·시간·타이머 정산·일지 포함을 같은 트랜잭션에 저장한다. 실패 시 모두 되돌린다.

## Direction contract

THESIS: 기존 진행중 업무에서 오늘 작업분을 기록하고 바로 결과를 확인한다.

OWN-WORLD: DESIGN.md의 흰 모달, 뉴트럴 구분선, 시스템 글꼴, 인디고 저장 버튼을 그대로 사용한다.

STORY: 업무 선택 → 오늘 작업 기록 → 내용·오늘 총 시간 확인 → 저장 → 오늘 시간과 누적 시간 확인.

FIRST VIEWPORT: 업무명과 날짜 아래 타이머 시작·일시정지·재개, 작업 내용, 시간 입력, 빠른 시간 버튼, 저장 액션을 한 열로 배치한다. 모바일에서는 기존 모달의 화면 내 스크롤을 사용한다.

FORM: 사용자와 확정한 기존 화면 확장. 신규 시각 방향 추첨과 이미지 시안은 적용하지 않는다.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 검증

`node --test scripts/today-work-record.test.mjs`는 별도 SQLite 데이터베이스에서 수동 저장, 재저장, 타이머 시작·일시정지·재개·종료, 자동 시간 해제 후 측정, 날짜 경계, 충돌, 실패 시 원복과 기존 업무 보존을 검증한다.
